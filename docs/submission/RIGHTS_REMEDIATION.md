# 公開評価データの縮小と残る権利確認

2026-11-10。製品機能・本番環境・過去の実測値は変更していません。

## 現行公開範囲

ChartQA／OECD由来の評価記録は、元表を再現する見出し・全行・期待値・予測出力・原文応答・診断内の具体値を除外し、出典URL、資料単位のハッシュ、分割、採点情報、時間・費用・集計を残しています。17ファイルの原本と縮小版のSHA256は [PUBLICATION.json](../../evaluation/real-v2/PUBLICATION.json) に記録しています。原画像・原CSVを同梱しないことと、表内容を再配布しないことは区別します。

農水省・和歌山県の単純な統計値・ラベルと評価結果は、一般利用条件の根拠と加工内容を明記して公開を継続しています。原画像の個別許諾まで確認済みとは扱いません。詳細は [出典・条件・例外](../../evaluation/real-v2/LICENSE_DATA.md) を参照してください。

## 実測と再現性

- 元の抽出コード・採点基準・集計値・凍結記録は維持します。元表を必要とする再採点は非公開原本が必要で、公開縮小版だけで完全再現できません。
- 過去の265件成功は当時の試験結果です。今回の試験結果とは区別してください。
- 原本ハッシュを縮小版に合わせて書き換えていません。公開データ監査テスト2件は、縮小版の整合性と元表・応答の再配布防止を検査するものへ変更しました。元CSVとの値照合を公開版で実施したという主張はしません。
- `SUBMISSION_MANIFEST.json`、既存の提出検証JSONや過去監査書は作成時点の履歴です。現在のファイルハッシュを示すものとして使用しないでください。

## 全履歴の書き換えと残存リスク

ユーザーの明示承認に基づき、git-filter-repoでmainから到達可能な全履歴の対象データを縮小しました。元mainと全参照は非公開ローカルのミラー・bundleに保存し、公開バックアップブランチは作成しません。通常の削除コミットだけで処理したものではありません。

旧コミットIDのGitHub表示、キャッシュ、fork、外部コピーまで消えたとは保証できません。公開した事実や過去の利用の適法性が、履歴書き換えで解決するとは主張しません。GitHub側の残存表示の削除は別途相談事項です。大会運営への説明も本人対応事項で、相談・承認済みとはしていません。

チームメンバーは書換え後に新規cloneし、旧履歴をmerge・pull・pushしないでください。別PCに未反映作業がある場合は、データを含まない必要な変更だけを個別確認し、締切前に対応します。締切後の変更は大会規則に従います。
