## 実録画の根拠と編集方針

- 教員は既存アカウントで実ログイン。認証情報の入力中は収録せず、ログイン後の同じセッションで実操作。メールアドレスと既存教材一覧は録画ブラウザ内だけで非表示にした。セッション・トークンのファイル書き出しは行っていない。
- 実Gemini解析は1回、HTTP200。要求操作から応答までは約4.894秒（今回1回のみ）。合成図の12・18・9、タイトルと単位『人』を取得した。
- タイトルを教員確認済みへ変更し、項目・数値・単位を照合。安全性の実演として9を意図的に空欄へ変更した。AIが9を誤読したという演出ではない。
- 新規教材を保存・承認し、12・18・nullの変更できない公開版を作成。別の未ログインブラウザで表・キーボード比較・nullの計算除外を検証した。学生のGemini呼び出しは0回。
- 解析以外の操作間を編集し、画面の静止保持も行って映像上に明記。Geminiの解析待機は短縮・倍速化していない。
- 収録元の承認チェック文には狭い折り返しがあるため、完成版は承認処理・完了表示を中心に編集。本番UI・CSSは修正していない。
- 既存20件の承認教材は全件hash不変。追加は今回のデモ教材1件。Cloud Run設定・Firebaseユーザー／権限・既存教材は変更していない。
- Gemini試験の既存5米ドル上限内で、1生成と1入力計測の保守予約を記録。クラウドの厳密なtoken usageはブラウザに返さないため、実請求額を断定しない。
