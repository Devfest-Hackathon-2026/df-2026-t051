# 約90秒デモ台本

実画面と実測に基づく台本。録画ファイル自体は未作成。現在はユーザー承認後に一般公開済み。通常URLで教員ログインし、承認済みの学生教材は匿名ブラウザで開ける。

| 時間 | 画面・操作 | 説明 |
|---|---|---|
| 0–10秒 | 教員画面、元画像 | 「画像のグラフは、視覚障害のある学生が数値を自力で比べにくい。ChartBridgeは教員の確認を通じて橋渡しします」 |
| 10–25秒 | ログイン済み教員がPNG/JPEG登録→実Gemini解析 | 「Geminiが項目・値・単位を構造化します。表示されるのは教員確認前の抽出データです」 |
| 25–40秒 | AI抽出と教員確認データを並べ、値・単位を照合して修正 | 「間違いは人が直します。読めない数値は未確定、桁表記が混じる値は自動換算しません」 |
| 40–55秒 | 保存→確認チェック→承認 | 「承認すると変更できない配布版を作ります。原画像と未承認データは本人だけが見られます」 |
| 55–75秒 | 学生用リンク→Tab・矢印・Enterで2値比較 | 「学生は承認された同じ値の表から自分で比較できます。閲覧時にはGeminiを使いません」 |
| 75–85秒 | 未確定例と1件だけの確定値表示 | 「未確定を0にせず、全体の最大最小が分かったとは表示しません」 |
| 85–90秒 | 実測と限界 | 「日本語追加20枚は15枚完全一致、単位が曖昧な24値は保留。別出典の最終1枚は全一致ですが、一般精度の保証ではありません。実読み上げは未検証です」 |

事前準備：教員本人がログイン、明瞭な合成画像（実解析であることを明示）または出典付きの使用許諾を確認した実教材原図、未確定の試験教材を開ける状態にする。デモのためだけに実教材の失敗を隠したり、固定デモを実Gemini解析と呼ばない。
Gemini処理は変動する。90秒を超える場合は「実測の待機時間を編集で省略」と明示して録画編集するか、解析済み教材を見せる。成功率や読み上げ結果を音声演出で捏造しない。
