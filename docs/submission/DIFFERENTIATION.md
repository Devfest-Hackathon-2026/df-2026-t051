# 比較対象とChartBridgeの焦点

ChartBridgeの焦点は、画像から説明文を出すことだけでなく、教員が誤り・不明値を照合し、固定した配布版から学生が自分で数値を探索できる一連の運用である。

| アプローチ | 主な価値 | ChartBridgeで組み合わせた範囲 |
|---|---|---|
| 教員が画像を見て説明・手入力 | 内容を人が確認できる | AI抽出を入口にし、修正・承認の責任と原文を残す |
| 図の説明文を得る | 全体像の把握を助ける | 表の値を1項目ずつ確認し、任意の2値を本人が比較できる |
| 画像→表の研究手法（DePlot） | 画像からデータへ変換 | 検証済み配布版、教員認可、元画像照合、学生向け操作までを製品内で接続 |
| データを持つチャートのアクセシビリティ（Highcharts等） | キーボード・支援技術による探索 | 教材画像しかない出発点から、教員の承認を通じて探索可能なデータへ橋渡し |

これは各方式の主要な対象の比較であり、他製品の機能が一切ないと断定するものでも、網羅的な市場調査でもない。競合に対するユーザー試験・作業時間比較は未実施。世界初・最高精度・点数保証は主張しない。

社会課題への接続：学生が画像説明を誰かに依頼するだけで終わらず、同じ承認済み数値から「どちらが大きいか」「差はいくつか」を自分で確かめることを目指す。当事者による読解・学習効果の試験は今後の検証課題。
