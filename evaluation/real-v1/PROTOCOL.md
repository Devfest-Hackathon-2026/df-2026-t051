# 実教材追加評価 — 実行前に固定する採点

対象：農林水産省の2024年公開教育ページに掲載された原図6枚・30値。出典・利用条件・SHA256・正解はmanifestに記録。原図を描き直さず、画像全体を入力する。
元画像は再配布せず、`prepare_real_evaluation.py`で出典URLから取得してハッシュ確認する。サイトのPDL1.0既定条件・出典表示・第三者権利の例外を確認。ロゴ・公式キャラクター画像は対象に含めない。評価結果は農林水産省の作成・保証を受けたものではない。
現況の2026年生産量を示すものではなく、公開当時の教材の印字読取を評価する。

全6枚は単系列・縦棒・5項目・全数値ラベル付きで構造条件に適合する。ただしR02/R03/R05は「6万4千」等の複合表記と「千t」軸の併用があり、数値・単位の解釈を要する挑戦条件。単純なアラビア数字表記と別集計する。
全ラベルがない統計資料はscreened_outに記録し、この6枚の分母へ混ぜない。

採点は既存fixed-v1と同じNFKC/casefold/空白除去、印刷順の厳密比較。値の正解は「軸の単位」に揃える。例：千t軸の6万4千tは64千t。
副指標として、出力unitが明示的に`t`/`トン`/`千t`/`千トン`/`万t`/`万トン`のときだけtへ換算し、意味上同値かを採点。括弧と空白は除去して正規化する。任意の単位推測や人手の出力修正はしない。
数値だけ合っていて単位が違う、またはその逆のケースは全体成功としない。null・unsupported・API例外も分母から除外しない。
タイトル・単位・カテゴリ・値・null・失敗・実API wall timeを全個票に記録。モデルと抽出プロンプトは既存のまま、1枚1回・自動再試行なし。SDK既定動作は維持。
測定後にこのセットに合わせて抽出器を変更した場合、独立評価とは呼ばない。実教材でも同一出版社・同一ページに偏るので、一般化された成功率とは解釈しない。
