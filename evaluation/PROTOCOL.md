# 固定評価 v1 — 評価前に固定する仕様

開発用の`backend/tests/fixtures`とは別の、合成教材18枚。人の写真や外部教材は使用しない。
全画像が単系列の縦棒グラフ、全数値ラベル付き、2〜12カテゴリ。全数値は読取り可能な確定値を正解とする。
easy 6枚、standard 8枚、hard 4枚。日本語・英語、PNG 12枚・JPEG 6枚、整数・小数・負数・0・カンマ表記、無単位2枚、8〜12項目、折返し項目名、小さめ文字・薄色棒・JPEG圧縮を含む。
難易度は生成条件による事前分類で、実際のモデル成績による分類ではない。実教材や視覚障害当事者による読解試験の代替ではない。

## 固定と独立性

`generate_fixed_evaluation.py`で画像・正解JSON・各SHA256を固定する。既存manifestの上書きは禁止。
最初のAPI評価前に、データ、採点コード、既存Geminiプロンプト・モデル・スキーマのハッシュを記録しGitへコミットする。
評価は1画像1回、順番はID順。自動再試行・成功例の選別はしない。失敗やタイムアウトも18枚の分母から除外しない。
結果を見てプロンプト・抽出コード・スキーマを調整した場合、このセットは開発データへ格下げし、独立評価と呼ばない。別データで再評価する。
現行プロンプト・抽出ロジックは評価結果に合わせて変更しない。

## 採点（事前定義）

- JSONを既存Extractionスキーマで検証。エラー／unsupportedは画像失敗。
- 数値：印刷順の同じ位置の数値を`Decimal(str(value))`で厳密一致比較。null・欠落・エラーは不正解。カテゴリ数不一致の余分な出力も別途記録。
- カテゴリ：印刷順。Unicode NFKC＋casefold化後に空白・改行を除き比較。英字の大文字小文字以外の言い換えや翻訳は許容しない。
- 単位：NFKC＋casefold＋空白除去の厳密一致。無単位の正解はnull。類義語への人手置換はしない。
- タイトルも同じ文字正規化で記録するが、必須主指標は数値・カテゴリ・単位。
- 画像完全一致：supported、カテゴリ数、全ラベル・数値・単位・タイトルの全条件一致。
- 全18枚のセル分母を使用したmicro集計と、画像ごとの内訳を両方保存する。
- null処理：この18枚では確定数値のnullは棄権・不正解として数える。曖昧値を推測しない安全性は別の開発用不鮮明画像・API／計算テストで検証し混算しない。
- 時間：既存`normalize_image`→`extract_chart`の実測wall time。ネットワーク・Gemini・スキーマ検証込み、Cloud Run／GCS保存時間は含まない。SDK内部retryはSDK既定のまま、ハーネスではretryしない。平均・中央値・最大・全個票を保存。

同じ環境・固定モデル`gemini-3.8-flash`を使用。キー値、token、個人情報を結果に含めない。
