# 開発セットの単位不一致の照合

対象：development-cycle1。Codexが原図・公開CSV・返却JSONを照合。独立した人間の別査読は未実施。
固定の字面比較で不一致17画像49セル。数値は182/182で、誤倍率や別通貨等の物理的に誤った単位との併用はこのセットでは確認しなかった。自動B件数を49件の倍率事故と呼ばない。

|---|---|---|

これらを都合よく同義語として採点器へ後付け追加しない。残る差を消すためだけのプロンプト変更・文字削除は行わず、改善サイクルは1回で終了する。主見出しのみをタイトルにするため、観測年・対象集団等の文脈は必ずしも公開データへ全て残らない。教員は原図の副題も確認し、教材に必要な文脈を承認前のタイトル・単位へ補う必要がある。

日本語の既知3枚では、単位の省略が曖昧な9セルを修正前後ともnullとして保持した。機械集計のunnecessary_null/Eは「独立した既知正解に対して保留した候補」の名称であり、この診断用3枚について不適切な保留9件と断定しない。primaryの開発／最終セットとは分ける。
